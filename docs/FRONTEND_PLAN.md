# 前端开发计划（FRONTEND_PLAN）

> 规矩见 `AGENTS.md` §11「前端预览规矩（强制）」：**先出真实预览图 → 用户确认 → 才上线**；
> 非「明确且单一」的改动必须给 **≥3 种样式方案**。本文只排步骤，不写实现。

## 0. 现状与约束

| 项 | 现状 |
| --- | --- |
| 渲染方式 | askama 服务端渲染 + 少量前端岛（Vue/TS，`web/src/*` → `static/islands/*.js`） |
| 样式 | `site.css` / `home.css` / `forum.css` / `auth.css`（其他开发者在改）+ 老 `app.css` |
| 预览 | `scripts/preview.mjs`：dev 库只读快照 + 登录态 + 整页截图 + 空壳断言 |
| 上线路径 | 本地 → `main` → `deploy/dev.sh`（/dev）→ 用户看图确认 → `deploy/promote.sh`（生产） |
| 硬预算 | 列表页 HTML ≤ 30 KB、首屏 JS ≤ 60 KB（brotli 后，`scripts/check-budgets.mjs`） |
| 协作 | 前端多人同时在改 → **动手前先在群里认领页面**，避免两个人在同一模板上对撞 |

## 2. 分批步骤

### F0 打底（半天）

- 认领页面、统一设计令牌（颜色/间距/圆角/按钮/徽标），把 `site.css|home.css|forum.css|auth.css|app.css` 收敛成一套；
- 明确「预览 → 确认 → promote」节奏；`scripts/preview.mjs` 加 `--pages` 覆盖（已有）与选点截图（后续）。
- 验收：任意页面截图模板改动都能量化对比（同一份快照、同一份代码）。

### F1 帖子详情页（第一批，收益最大）

范围：issue 面板、资源帖状态徽标 + 作者改状态、置顶/精华徽标、作者头衔与等级、链接解析、待审修改提示。

**需要你拍板的分歧（我会各出 3 种真实预览图）**：
1. 页面信息密度：A 紧凑 / B 舒适留白 / C 三栏（作者·资源·issue 固定右栏）；
2. issue 面板形态：A 内嵌折叠 / B 独立子页 / C 右栏抽屉；
3. 资源帖状态呈现：A 文字胶囊 / B 图标+文字 / C 进度条式。

验收：`node scripts/preview.mjs` 出图（含登录态与空态两种），你选定后我实现 → 发 /dev → 你看真机 → promote。

### F2 列表与发现页

分区导航改读库（含归档隐藏）、置顶/精华徽标、搜索接后端、精选位、分页与空态。
分歧点：卡片密度与徽标位置（并出 3 版）。

### F3 管理面板扩展

分区管理（拖拽排序/归档/门槛）、用户组与规则矩阵、头衔管理、待审修改队列、域名（超管）、横幅（超管）、按组推送、按权限隐藏入口。
分歧点：规则矩阵布局（表格/卡片分组/向导式）。

### F4 用户侧

收款码（上传 + 主页展示）、头衔佩戴、等级经验进度、横幅展示与「知道了」、私信/收藏等既有页面的令牌统一。

### F5 打磨与验收

空态/错误态、明暗两套、移动端断点、页面体积预算、`scripts/smoke.ps1` 增加前端检查项（关键页 200 + 关键元素存在）。

## 3. 每批的固定动作（不许跳）

1. 出预览图（≥3 方案，除非是明确单一改动）→ 2. 用户选 → 3. 实现 → 4. `fmt/clippy/test` 门禁 →
5. PR 合入 `dev` → 6. `SC2CLUD_BRANCH=dev bash deploy/dev.sh` → 7. 用户看 `/dev` 确认 → 8. PR 合入 `main` → 9. 按项目确认流程 `deploy/promote.sh`。

## 5. 精华与首页排序进度（2026-10-10）

已实现帖子精华入口及门户/论坛共用排序：默认综合、最新互动、点赞最多、最新发布；URL 保留筛选与分页，切换排序回第一页。精华权限、幂等事务与审计规则见 `PERMISSIONS.md`。

基础分 B = 有效点赞数 + 3 × 有效一级评论数；普通帖为 B，精华帖为 1.2 × B + 20，不取整、不衰减，置顶仍优先。普通热门帖可超过精华帖，取消点赞/删除评论即时反映实际数据。打赏、收藏与 issue 数量不计分。

最新互动取发布时间、有效普通评论、新建 issue、有效 issue 回复时间的最大值；关闭/重开 issue、编辑正文、点赞、收藏不顶帖，删除回复后回退到上一有效时间。普通评论仍无 parent_id/reply_to，全部单层；issue 回复独立存储，只贡献互动时间。

DEV 交付已补整套校验：本机 build 清理旧 islands 并生成来源与哈希清单，经 ssh-skill 上传完整 islands，DEV 不读取生产旧 JS；promote 使用已验收 DEV 二进制与完整静态并备份旧整套。部署行为测试不调用真实服务器。浏览器真实场景 QA 在任务3完成；远程 DEV 发布与用户验收由控制者安排，本任务不执行生产 promote。
