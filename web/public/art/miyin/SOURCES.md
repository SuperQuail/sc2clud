# 弥音图片来源与用途

本目录图片由网站维护者在本次设计调整中提供，按显示尺寸等比缩小并转为 WebP；没有修改画面内容。

| 文件 | 用途 |
| --- | --- |
| wisdom-160.webp | 搜索无结果 |
| welcome-400.webp | 注册欢迎插画、频道待创作状态 |
| wink-520.webp | 首页与登录欢迎插画 |
| genius-160.webp | 发帖页创作提示 |
| smile-160.webp | 通知、收藏、回复的空状态 |
| image-unavailable-480.webp | 帖子配图加载失败（也用于论坛快速预览、封面） |

最后两张附件为同一张错误插画，使用最后一张附件生成占位资源。占位图仅在真实图片失败时加载；正常图片、头像及无封面帖子不受影响。
