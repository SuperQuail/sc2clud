# 方向 B · 内容优先（style-b）

解决什么问题：**从分享链接点进来的新访客**。他带着一个帖子链接落地，停留 30 秒，
要在不熟悉的站点里快速判断「这里有没有我要的东西」。所以这一版把版式让给内容：
大留白、大标题、封面图主导，一屏只讲一件事。

## 两个变体

|  | v1 单栏阅读流 | v2 三栏密度档 |
|---|---|---|
| 栅格 | 单栏 64rem，无侧栏 | 左导航 + 主区(52rem) + 右信息栏 |
| 导航 | 顶栏胶囊，横向可滑 | 左栏竖排列表（≥1024 出现） |
| 封面 | 行右侧缩略图（窄屏落到标题下） | 卡片头图 16:9 |
| 行距 | 每条 72–88px，一条一行 | 两列卡片网格，间距 16px |
| 置顶/精华 | 左侧竖线 + 徽标 | 卡片左侧色条 + 封面角标 |
| 每屏条数 | 约 3 条 | 约 4–6 张卡片 |
| 翻页 | 触底自动加载 + 按钮兜底 | 显式「加载更多」 |

## 取舍

- **推荐 v1**：它最贴合「内容优先」这个方向，也更省 —— 首屏没有右栏的三块统计和左栏导航，
  DOM 更小、LCP 更稳；单栏阅读流对长标题与中文正文更友好。
- v2 的价值是**回访者**：左栏常驻版块、右栏「今日社区 / 活跃作者 / 最新回复」，
  一次点击能到的地方更多。代价是首屏多两栏装饰性内容，且三栏在 1280 以下会退化成双栏。
- 两版共用同一份假数据形状（字段名对齐后端方案 §21.3），换掉 `fakeTopics` 即可接真接口。

## 已知边界

- 封面是**内联 SVG 画的抽象图**，不是图片：`<img>` 里的 SVG 拿不到 CSS 变量，也拿不到
  `currentColor`（都实测过，会整张退成黑色）。真实项目这里换成 `/img/<hash>` 缩略图。
- 头像用 Ring UI `Avatar` 的 fallback（渐变 + 首字母）。**size 只能取 16/18/20/24/28/32/40/48/56**，
  取 22/26/30 会让 Ring UI 的 fallback 抛 TypeError（库的洞，已避让）。
- `Avatar` 的 `alt` 是库写死的英文 `User avatar`，且不走项目的令牌；要中文或要改形状
  只能在 `src/ui/` 里包一层。
- 演示开关（正常 / 空 / 错误）只为本页预览服务，接真接口后应删掉。

## 自检

`pnpm exec vitest run src/preview/style-b`：两个变体都能挂载、能从加载态走到列表，
并断言封面是内联 SVG 且页面里不出现 `data:image`（防止再退回不可见的黑色封面）。
