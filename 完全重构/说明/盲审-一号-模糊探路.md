## 2. 做不成的事

> 每条格式：**想做什么 / 实际发生 / 期望 / 复现步骤**。

### 2.1 打不开题面给的地址（http）
- **想做什么**：打开 `http://191.40.41.97/dev/devroom/`。
- **实际发生**：Chrome 直接报 `ERR_BLOCKED_BY_CLIENT`，页面是错误页；换成 `https://` 才通，但先弹"您的连接不是私密连接"（证书名不匹配），要手动忽略才能继续。
- **期望**：题面给的地址复制到浏览器就能看到站点；至少给个能直接打开的 https 入口或说明。
- **复现**：地址栏输入 `http://191.40.41.97/dev/devroom/` → 被拦。`https://191.40.41.97/dev/devroom/` → 证书警告 → 继续 → 正常。
- **诚实备注**：明文 http 被拦是我这个浏览器（HTTPS-First 策略）的行为，换 `http://neverssl.com/` 也一样；所以这条有一半算我的环境。但"给出的地址打不开 / 另一个地址要跳过证书警告"这件事本身是真实的第一次接触体验。

### 2.2 注册的最后一步没有反应
- **想做什么**：注册账号并激活。
- **实际发生**：注册表单能填、能提交，页面也确实跳到"输入验证码"；填 6 位数字后点"激活账号"，**页面没有任何变化**——没有成功提示、没有报错、没有跳转、没有 toast，输入框里的码也还在。倒计时的"重新发送验证码（60 s）"倒是会一秒一秒往下走。
- **期望**：点"激活账号"至少要有三种结果之一：激活成功并进入社区、验证码错误、或者"这是演示页，不会真的激活"。现在什么都看不出来。
- **复现**：`?page=16-auth` → 演示控制台切"注册" → 填完 5 个输入框 → 点"注册" → 落到"输入验证码" → 验证码填 `123456` → 点"激活账号"。

### 2.3 "发帖"没有反应
- **想做什么**：发一个新帖。
- **实际发生**：首页右上"发帖"按钮点了没反应（URL 不变、没有编辑器、没有弹层、没有"请先登录"）。我翻遍 17 个页面，**没有一页是"写帖子"的**：有富文本编辑器控件页（09）、有帖子内容页（12），但没有"标题 + 分区 + 标签 + 正文 + 附件 + 预览 + 发布"的页面。帖子页侧栏的"发帖"是一个链接，指向 `/b/campaign/new`。
- **期望**：既然有"发帖"按钮和"发布战役"按钮，就应该能落到一个发帖页；就算没做，也该在按钮上写"未接线"或点了给个提示。
- **复现**：`?page=14-home` → 点标题右侧的"发帖"按钮 → 无任何变化。

### 2.4 回帖发不出去
- **想做什么**：在帖子下面回复。
- **实际发生**：评论框能输入（右下角字数从 0/10000 变成 8/10000，按钮从灰变亮），点"发布"后**文字原封不动留在框里**，评论数还是 128，列表里没有新评论，也没有任何提示。
- **期望**：要么发出去了（列表 +1、输入框清空），要么明确说为什么发不出去。
- **复现**：`?page=12-topic` → 页面下方"评论 128"下面的输入框 → 输入任意文字 → 点"发布"。

### 2.5 首页的"加载更多"和"看空态"没有反应
- **想做什么**：翻更多帖子 / 看空列表长什么样。
- **实际发生**：按钮文字"加载更多（还剩 4 条）"点完仍然是这句话，列表条数不变（前后都是 8 个 article / 11 个 li）；"看空态（把列表清空）"点完列表也没被清空，按钮文字也不变。对比：演示控制台里那个"模拟空态"按钮是**真的有用**的（我点了以后列表从 8 条变成 0 条）。也就是说同一个动作，控制台版本能跑、页面内版本不跑。
- **期望**：点"加载更多"应该加载出剩下 4 条；点"看空态"应该真的把列表换成空态。
- **复现**：`?page=14-home` → 拉到列表底部 → 点"加载更多（还剩 4 条）"；再点最下面的"看空态（把列表清空）"。

### 2.6 关注 / 发私信 / 设置 三个都不动
- **想做什么**：关注作者、私信作者、进个人设置。
- **实际发生**：`?page=11-profile` 上"关注"按钮点了不变"已关注"；"发私信"没反应；"设置"没反应；"帖子 / 回复 / 收藏 / 赞过"四个 tab 点了内容也不换（一直显示帖子列表）。
- **期望**：关注要变成"已关注"（数字 +1），设置要能进设置页或至少说明"设置页未做"。
- **复现**：`?page=11-profile` → 点头像右侧"关注"。

### 2.7 举报 / 分享 没有反应
- **想做什么**：举报一篇帖子、把帖子分享出去。
- **实际发生**：`?page=12-topic` 的"分享"和"举报"点完都没有弹层、没有菜单、没有复制提示（页面里 `[role=dialog]` 数量始终 0）。08 评论区页自己也写着"待补 · 未做：举报菜单"。
- **期望**：举报至少要弹出理由选项；分享至少要弹出链接。
- **复现**：`?page=12-topic` → 点赞那一行的"分享" / "举报"。

### 2.8 评论区的赞踩没有反应（但帖子页的点赞有反应）
- **想做什么**：给一条评论点赞/点踩。
- **实际发生**：`?page=08-comments` 里，按钮的可访问名是"点赞，当前 12 个赞"，点完还是"点赞，当前 12 个赞"，**数字不变、也不变"取消点赞"**；点踩同理。而这一页自己的说明写着"赞踩传了 onVote，点了要有反应（同向再点=取消）"。
- **对比**：`?page=12-topic` 主楼的"点赞"是**真的会动**的：236 → 237，名字变成"取消点赞，当前 237 个赞"。同一个控件，两个页面行为不一致。
- **期望**：同一套控件在哪儿都该有反应。
- **复现**：`?page=08-comments` → 第一条评论（陆战队员）下的"点赞，当前 12 个赞" → 点两次。

### 2.9 长评论"展开"没有反应
- **想做什么**：展开被折叠的超长评论。
- **实际发生**：点"展开"后页面文本长度没变（前后都是 2190 字符），评论也没展开。
- **期望**：展开后应看到全文。
- **复现**：`?page=08-comments` → 第 3 条长评论（雷神，带 ⑨ 条要点那条）下的"展开"。

### 2.10 富文本"存一次（模拟发布）"没有反应
- **想做什么**：验证"写正文 → 存 JSON+HTML → 读回来"这条往返。
- **实际发生**：在正文里写了 12 个字（计数显示"12 / 20000 字"），点"存一次（模拟发布）"，下面**仍然写着"还没存过"**，没有出现存的 JSON/HTML，也没有读回来的渲染。
- **期望**：这是演示"往返测试"的按钮，点了应该出现存下来的内容。
- **复现**：`?page=09-rich` → 点正文区输入几个字 → 点"存一次（模拟发布）"。

### 2.11 管理后台 12 个导航项里 7 个点了不换内容
- **想做什么**：逐个看管理后台的每个面板。
- **实际发生**：点完后**内容有变化**的只有 5 个：用户管理、角色与权限（角色与权限矩阵）、分区管理（分区管理 · BoardACL）、帖子审核（帖子审核队列）、举报处理（举报处理队列）。点了**没有反应**（内容停在上一个面板）的 7 个：打赏核验、头衔目录、发信账号、AI 审核、站点设置、审计日志、自检面板。
- **期望**：要么渲染面板，要么明确写"未做"，不要静默不动——静默时我会怀疑是自己点歪了。
- **复现**：`?page=15-admin` → 依次点左侧导航"打赏核验""头衔目录""发信账号""AI 审核""站点设置""审计日志""自检面板"（每个都有计数角标，看起来是能点的）。

### 2.12 管理后台的危险动作点了没有确认、没有结果
- **想做什么**：归档一个分区、停用一个账号、给用户发头衔。
- **实际发生**：
  - "删除分区"是**灰的/禁用**的（页面自己解释了：有帖子的分区只能归档）——这个设计我认同；
  - 但"归档分区"点了**没有任何反应**：没有"理由必填"的输入框（页面文案说"危险动作：归档与删除都要写审计；删除比归档更狠，理由必填"）、没有二次确认、没有 toast；
  - "停用账号""发头衔"（右栏用户详情里）点了同样没有反应；
  - "添加版主""免职"也没反应。
- **期望**：危险动作至少要有二次确认（最好带理由框），并在动作后给结果提示。
- **复现**：`?page=15-admin` → 左栏点"分区管理" → 页面底部"归档分区"，或右栏"停用账号"。

### 2.13 站内链接全部落到 404，而且 404 页回不来
- **想做什么**：从首页去看分区、去发布战役、看版规/关于/联系。
- **实际发生**：首页的"浏览分区"（→ `/b/campaign`）、"发布战役"（→ `/b/campaign/new`）、底部的"开始使用"（→ `/signup`）、页脚的"关于 / 版规 / 联系"（→ `/about` `/rules` `/contact`）、帖子页的"发帖"——**全部落到一个"404 页面不存在。"的页面**。这个 404 页有自己的顶栏："开发页面（临时） / SC2clud / 首页 / 下载 / 搜索"，但它的"首页/下载/搜索"指向 `/dev`、`/dev/download`、`/dev/search`，其中"下载"和"搜索"**也是 404**，而 `/dev` 是一个"重写版前端骨架（F0）"的占位页，上面有个"后端探针：**不可用：未知错误**"。
- **期望**：设计参考房间里的链接即便不做目标页，也应该指向房间自身的其它页面（或至少标记"这是外链/未做"），而不是把我扔到一个和当前房间无关的 404，还回不去。
- **复现**：`?page=00-showroom` → 点"浏览分区"，或拉到页脚点"关于"。任意 `/xxx` 路径同理。

### 2.14 私信发出去了，但输入框不清空
- **想做什么**：给"陆战队员"发一条私信。
- **实际发生**：点"发送"后消息**确实进了会话**（左侧会话预览也更新成这条），但右下角输入框里**文字还在**，计数还是"12 / 500"，按钮还是亮的。所以同一条内容可以被再发一次。

### 2.15 反馈区的"发布"看不出到底发出去没有
- **想做什么**：在问题反馈 #128 下跟一条评论。
- **实际发生**：写完点"发布"，页面文本里出现了我这句话（出现 2 次），但评论数没变、没有"刚刚"、也没有排序变化，我**无法判断是发出去了还是只是还在输入框里**；"待处理 Open（当前：开启中，关掉即 Closed）"这个开关点了也没变。

- **复现**：`?page=13-issue` → 右栏详情里输入框写一行 → 点"发布"；再点"待处理 Open"。

### 2.16 找不到全站搜索

- **复现**：任意页面找搜索框；或点 404 页顶栏"搜索"。

## 3. 看不懂的地方

1. **每个页头都有一段开发说明**（"业务代码只允许使用已登记（src/devroom/registry.ts）的控件…未登记会被 pnpm gate:controls 挡住"、"已登记控件：41 个"）。作为"刚听说这个网站的人"，我不知道这是网站的一部分还是后台漏出来的东西。
2. **页面正文里全是内部编号**："拍板 §11"、"前端方案 §6"、"后端方案 §9.8"、"D6 判定顺序"、"13.2 / 13.3 / 21.2"、"RBAC权限树设计.md §1"、"DB §4.1 不变量"。我猜这是给设计评审看的注解，但它和"真实页面的样子"混在同一列里，我第一眼分不清哪句是给用户看的。
3. **演示控制台和真页面混排**：有些页面的控制台是虚线框（16-auth、11-profile），有些页面没有框，直接就是一排按钮（12-topic 的"审核中/正常/未通过"、14-home 的"模拟空态"、13-issue 的一些开关）。我得靠上下文猜哪个是真控件。
4. **身份状态不明**：12-topic 右侧显示我"已关注"这个作者，但同一页左侧又写"游客可读，发帖需登录"。我到底是登录了还是没登录？注册流程走完也没告诉我登录成功。
5. **"发布"按钮的可用/不可用会骗人**：我第一次在评论框里输入 8 个字时，快照显示"发布 [disabled]"；重新加载后再输入 8 个字，它又是可点的了。我判断不出是我的问题还是控件的问题（后来确认是渲染时机，但当时确实看不懂）。
6. **同一个帖子的数字对不上**：首页第一张卡片是《余烬》第三章完整版发布（128 回复 / 96 赞 / 4203 浏览）；帖子内容页那篇（第三章「余烬」平衡性改动说明）是 128 回复 / **236 赞** / 74 收藏 / 4203 浏览；个人主页的帖子列表里又有一条"第三章「余烬」发布公告与更新日志 · 128 回复 · 4203 浏览"。三个标题、两组数字。我**不确定它们是同一篇帖还是三篇帖共用了一份假数据**——如果是同一篇，那数字是矛盾的。
7. **"自动检查中 / 已转人工" 是什么**：帖子页顶部那组按钮点了会变，但它和"审核中/正常/未通过"是两个维度，页面只写了一句"真实页面由后端 review_state 决定，没有这个控件"。

## 6. 我自己的边界（哪些是我不熟，不是站的问题）

1. **我不确定"设计参考房间"的验收标准**。我按"这就是一个真实页面"来测试，所以"按钮点了没反应"我一律记成问题。如果这个房间的规则本来就是"只验外观、不接线"，那第 2 节里一半的条目应该降级成"已知"——但即便如此，**点了完全没反馈**仍会消耗探路人的时间（我至少重复点了十几次）。
2. **我没混过国内外的星际争霸战役社区**（NGA、SC2Mapster、地图作者 QQ 群那种）。所以第 5 节里"应该有什么"是我按通用论坛 + 单机战役 Mod 社区推的，可能漏掉这个圈子特有的东西（例如：地图上传到战网的地图大厅、Arcade 地图、合作指挥官的差别；战役的"三章/关卡"命名习惯；国内作者常用的网盘/提取码文化——后者站点里倒是有）。
3. **我不知道 09–16 是否已经是最终形态**。如果它们是"第一版草稿"，我的很多"没有"其实只是"还没轮到"。
4. **我只测了一个浏览器、一个视口（1280×720，无头）**。移动端、Safari/Firefox、触摸、输入法中文候选、粘贴图片，我全都没测。
5. **我没有登录态**。我不知道登录之后那些灰的/没反应的按钮会不会变（例如"发帖"是不是因为没登录才不动）。站点也没有真的账号系统让我登进去确认。
6. **我读了打包后的 JS 来找 URL 参数名**（`?sponsor=` `?review=` `?view=` `?panel=` `?kind=` `?screen=`）。这一步不是普通用户行为，属于"我找不到入口时用开发者手段确认"。因此对于这些参数，我只能说"页面上没有告诉我它们存在"，不能说"入口不存在"。
