# 任务书 05 · 设计对齐施工（2026-10-14）

> 目标：产品页改成**渲染 DevRoom 里原样的件**（用户定的规矩）。逐页差异见 [`设计对齐.md`](./设计对齐.md)。
> 本任务书把工作切成**互不重叠的文件作用域**，一个工作包一个 agent。

## 0. 协议（**每一步都做，不许攒**）

**这条是为「agent 中途因 API 波动挂掉、下一个能无缝接手」定的 —— 你的对话不会传给谁，只有仓库会。**

1. 一完成一小步就 `git commit`，**只 `git add` 你改的文件**（绝不 `git add -A` —— 工作区里有别人的在途文件）。
2. **同一个 commit 里更新你自己的进度文件** `完全重构/进行中/进度-W<N>.md`，四行固定格式：
   ```
   - [x] 这一步做了什么
     - 证据：<命令 + 输出关键行，不许写「已通过」>
     - 下一步：<文件 + 函数 + 改成什么>   ← 接手的人照着这句就能继续
     - 阻塞：<没有就写「无」；需要 Lead 动的写清要改哪个文件哪一行>
   ```
3. **接手规则**：新人 `cat 进度-W<N>.md` + `git log --oneline -8` 就能继续，不需要读任何对话。
4. 改文件一律 **edit 定点改**，不许整文件覆盖。**只碰你名下的文件**（第 1 节）。
5. **不许跑 `pnpm check`**：它会 `pnpm build` 清空 `dist/`，并发会互相踩。你跑
   `cd web && pnpm typecheck && pnpm lint && npx vitest run`；**收尾的 `pnpm check` 由 Lead 串行跑**。
6. **不许动**：`web/src/app/router.tsx`、`app/shell.tsx`、`lib/url.ts`、`styles/tokens.css`、`src/ui/**`、
   `preview/main.tsx`、`vite*.config.ts`、`package.json`、`deploy/**`。需要改 → 写进进度文件的「阻塞」。
7. 涉及渲染的改动**必须出图并看图**（`pnpm preview:build && node scripts/serve-preview.ts preview-dist 52NN`，
   端口按你的编号取，别用别人的），图放 `shots/preview/`。
8. 字段名**照后端 DTO 抄**（`forum/internal/**`），**不许照 DevRoom 的 mock 抄** —— 出过多次事故。
