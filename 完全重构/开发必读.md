# 开发必读（开工前 3 分钟看完，写完必须能过）

> **这是所有开发（人类与 AI 子 agent 都一样）的第一份文档。**
> 子 agent 的派发提示里必须原样包含本文的「§1 硬规则」与「§5 收工条件」两块，**不允许只说「去看文档」**——实测那样等于没说。

## 1. 硬规则（违反即返工，全部有机器检查）

| # | 规则 | 检查在哪 |
|---|---|---|
| 1 | **不允许在 HTML 里自己实现控件**。`<button>` / `<input>` / `<select>` / `<textarea>` / `<table>` / `<dialog>` 一律不许直接写 | `pnpm gate:ui`（告警）+ ESLint（挡住） |
| 2 | **需要新控件时，先做成库里的控件**：加到 `web/src/ui/`，写清 props 与可访问性，再从那里引用。**不允许**就地写一次性的 HTML | 同上；评审看 `src/ui/` |
| 3 | 控件优先用 **Ring UI**（`@jetbrains/ring-ui-built`）；Ring UI 没有的，才在 `src/ui/` 用 shadcn 风格自建 | 同上 |
| 4 | 只允许 `.ts` / `.tsx`，禁止 `.js` / `.jsx` / `.mjs` | ESLint + 目录扫描 |
| 5 | 颜色/间距只能用 `src/styles/tokens.css` 的令牌，不写死色值 | 评审 + `gate:ui` 可扩展 |
| 6 | 只允许在 `src/lib/api/client.ts` 里 `fetch` | ESLint `no-restricted-globals` |
| 7 | 不引入新依赖；不用第二套同类控件库 | 依赖 diff 评审 |
| 7.5 | **不许覆盖控件库的样式/尺寸变量**（要改就在 `src/ui/` 包一层，或换库）。令牌只做「引用库变量」的别名 | 评审 + 看 §11 |
| 8 | 后端：所有读写走 ent；原生 SQL 只允许在 `platform/search/pgsql` 与手写迁移里 | 评审 + golangci-lint |

## 2. 我要写个按钮/输入框，正确做法是什么

    // ❌ 错：就地写 HTML
    <button className="px-4 py-2 bg-primary">发帖</button>

    // ✅ 对：用 Ring UI（首选）
    import Button from '@jetbrains/ring-ui-built/components/button/button';
    <Button primary>发帖</Button>

    // ✅ 对：Ring UI 没有的（例如业务专用组合控件）→ 先加进库里
    //   web/src/ui/topic-actions.tsx  （在库里写一次，写清 props 与 aria）
    //   然后各处 import { TopicActions } from '@/ui/topic-actions';

**判断标准**：如果这段 HTML 你写了第二遍，它就该是 `src/ui/` 里的控件。

## 8. 出预览图（前端改动的交付门槛）

**规矩**：涉及界面的改动，**先出真实渲染图再交付**；新页面要给**三份不同设计**的预览图，由人挑，不许自己拍板。

仓库里已经备好工具，不需要装 Playwright（本机有 Chrome/Edge）：

    # 1) 起预览服务（独立入口，不进产品构建）
    cd web && pnpm preview:dev                  # http://127.0.0.1:5199/preview.html

    # 2) 浏览器看：?s=a|b&v=1|2&theme=light|dark
    http://127.0.0.1:5199/preview.html?s=b&v=2&theme=dark

    # 3) 出图（Chrome headless，无需额外依赖）
    chrome --headless=new --hide-scrollbars --window-size=1440,2600 \
      --screenshot=shots/preview/xxx.png \
      'http://127.0.0.1:5199/preview.html?s=b&v=2&theme=light'

**硬要求**（与旧站「预览规矩」一致）：

1. **必须真实渲染**：真组件、真数据（假数据也行，但必须是组件渲染出来的），不许贴设计稿；
2. **不许空壳**：图里要有顶栏/列表/侧栏等同页面的其它内容；
3. **预览与上线没有第二套代码**：同一套组件、同一份令牌；
4. **≥3 种方案**：除非改动明确单一（例如「把这个按钮改红」）；
5. **出图前先自己看一眼**：把图读出来确认没有布局塌陷——本项目已经出现过「侧栏太窄、文字逐字换行」这种只有看图才发现的问题。

预览产物不进仓库：截图放 `shots/preview/`（已 gitignore），预览构建产物在 `web/preview-dist/`（已 gitignore）。

**三个已踩的坑**（详见前端方案 §7.6）：

1. `<img src=*.svg>` 拿不到 CSS 变量与 `currentColor` → 想要主题色就**内联 SVG**；

## 11. 开发者房间（DevRoom）：没验证过的控件禁止直接用

**规矩**：写页面之前，控件必须先在 `web/src/devroom/` 里验证过，并登记进 `web/src/devroom/registry.ts`。
**没登记就 import，`pnpm gate:controls`（在 `pnpm check` 里）直接失败。**

为什么要这么严：本项目已经栽过一次——把 lucide 图标直接塞进 Ring UI 的 `icon` prop。
类型完全兼容（`IconType = ComponentType<SVGAttributes>`），**编译器不报、测试不测**，
但 lucide 默认 24×24、Ring UI 按 16px 固有尺寸排版，结果是**图标比文字大、按钮被顶高、基线对不齐**。
只有实物截图能发现。

### 加一个控件的标准流程

1. `web/src/devroom/pages/0N-<控件>.tsx`：把它的变体/尺寸/图标/禁用/加载/长文本/深浅色都渲染出来，每行左边写「为什么」；
2. 出图并**看图**：`cd web && pnpm preview:build && pnpm devroom`，浏览器开 `http://127.0.0.1:5202/devroom.html?page=0N-<控件>`；
3. 在 `registry.ts` 登记实测可用的 props 与坑；
4. 之后业务代码才能 import。

### 已经踩到的三条（都记在 devroom/README.md 里）

| 坑 | 正确做法 |
|---|---|
| 直接传 lucide 图标 → 错位 | 一律 `icon16(lucideIcon)` 包装（`@/ui/icons`） |
| `height="L"` 类型不通过 | 用 `ControlsHeight.S / M / L` 枚举 |
| 以为有 `size` prop | 没有；高度只走 `height` |

### 与其它门禁的关系

| 门禁 | 管什么 |
|---|---|
| `gate:ui` | 不许手写 HTML 控件（`<button>` 等） |
| `gate:controls` | 只许用**登记过**的 Ring UI 控件 |
| `gate:size` | 单文件 ≤ 500 行（超了要登记重构目标） |
| `gate:budget` | 产物体积（首屏 JS ≤150KB / CSS ≤40KB gzip） |
## 12. 路径只能有一个来源（src/lib/url.ts）

**规则**：任何「去哪」和「取什么资源」都必须经过 `web/src/lib/url.ts`：

    import { appPath, assetUrl } from '@/lib/url';
    <a href={appPath('b/campaign')}>          // 应用内跳转
    <a href={appPath('?page=01-interactive')}> // 换查询串
    <img src={assetUrl('miyin/wink-520.webp')} /> // public/ 下的静态资源

**不许**在组件里写 `href="/xxx"`、`src="/xxx"`、或自己拼 `'art/' + 文件名`。
门禁 `pnpm gate:urls` 会挡住这些写法。

**为什么**：同一份产物要同时跑在两个前缀下（生产 `/`、dev `/dev/`）。
路径散落各处时，一定有一处会坏——我们已经踩过两次：
① DevRoom 导航用了绝对路径 `/devroom.html` → 从 dev 跳去了生产端；
② 静态资源各写各的相对路径 → 换前缀就 404。
第三次不该再发生：所以把它收成一个函数 + 一条门禁。

**前缀本身**来自文档的 `<base href>`（Go 壳按实例注入，见 `src/lib/base.ts`），构建期常量 `BASE_URL` 不用——同一份产物要跑两个前缀。
